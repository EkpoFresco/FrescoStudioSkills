# studio-tests: instructions

Tests the rbx-studio skills and agents themselves (not a game). Driven by `/skill-test` and `/skill-improve` (project skills in this repo).

| File | Purpose |
|---|---|
| `catalog.yaml` | Every skill and agent with category, spec path, priority, last results. Generated by `node tools/gen-catalog.js` (keeps results). |
| `quality-rubric.md` | Per-category metrics for `/skill-test category`. |
| `skills/<category>/<name>.md` | Skill spec: static assertions, 3 cases (happy, relevance skip, edge), protocol compliance. |
| `agents/<category>/<name>.md` | Agent spec: static assertions, 3 cases (in-domain, out-of-domain hand-off, safety edge), protocol compliance. |
| `templates/` | Spec templates. |
| `results/` | Written by `/skill-test spec`. |

Rules:
- `studio/rbx-studio/CONTEXT.md` is injected into every Roblox session, so its rules count for every skill and agent. Cite it when a case relies on it.
- Specs assert the correct behavior. A failing assertion means the item is wrong until shown otherwise. Never weaken an assertion to make it pass.
- Fixture default: `.rbx-studio/project.yaml` from the template (`rigor: minimal`, `toolchain: mcp`, `team_size: 1`), Studio MCP connected, git repo with one commit.
- Audit passes when `node tools/gen-catalog.js --check` reports 0 problems.
